# Reader 0.51.0

本版本把完整备份从完全依赖手动操作推进到可选择的本机自动恢复点。功能默认关闭，Schema 保持 v12，不改变文章、附件、既有备份或恢复格式。

## 每日本机自动恢复点

- 数据安全中心新增明确开关；旧设置、缺失字段、非布尔值或读取失败都保持关闭。
- 开启后立即在条件允许时创建首份恢复点，此后每 24 小时最多创建一份。恢复点包含 SQLite 一致快照、全部附件和 SHA-256 manifest。
- 自动任务只创建本机明文 `.readerbackup.zip`，不保存、请求或复用任何备份口令；需要跨设备携带时仍应手动创建口令加密备份。
- 界面显示最近创建时间、保留数量和脱敏失败时间；自动恢复点继续可以从既有下载与恢复入口导出和验证。

## 有界轮转与后台协调

- 自动文件使用独立且严格的 `reader-auto-backup-…readerbackup.zip` 名称，只保留最新 3 份。
- 轮转不会删除普通手动备份、口令加密备份、修复前备份、恢复前备份或迁移快照恢复前备份；关闭开关也不会删除已经存在的恢复点。
- 导入任务运行时自动创建会延后；睡眠、低电量、严重热/降频或资料恢复锁会暂停服务。
- 自动任务使用单一进行中操作，恢复锁会等待已经开始的一致性快照与附件归档结束，避免跨越恢复安全边界。
- 创建失败不会阻断 Reader 或暴露原始错误；界面显示有限状态，后续轮询继续重试。本地诊断只记录“自动恢复点”、字节数和时间，不记录文件名、路径或内容。
