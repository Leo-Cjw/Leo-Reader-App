# Reader 0.17.0

本版本把“整理”从手动归档升级为可持续的动态秩序：文章仍只保存在原资料夹，但常用筛选可以成为会自动更新的智能资料夹。

## 智能资料夹

- 支持关键词、内容类型、标签、来源、原资料夹、阅读状态、收藏、高亮、附件和保存时间规则。
- 规则可选择“全部满足”或“任一满足”；标签还可单独选择匹配任一或全部。
- 结果计数实时来自本地 SQLite，文章状态、标签或高亮变化后无需复制内容。
- 提供完整规则预览、编辑、删除和拖动排序；删除动态视图不会移动或删除文章。

## 直接整理

- 文章卡片可直接拖到左侧普通资料夹；批量选择后拖动会一次移动全部所选内容。
- 资料夹管理器支持同级拖动排序，智能资料夹列表也可以拖动排序。
- 所有拖放写入复用现有原子批量接口，失败时保留原状态并给出错误提示。

## Local-first 数据闭环

- Schema v8 新增 `smart_collections`，规则和顺序随 SQLite 完整备份迁移。
- 规则在服务端规范化并编译成受限查询，不接受 SQL、HTML 或可执行内容。
- 完整备份恢复测试证明智能资料夹 ID、名称、规则和动态计数可以完整往返。

## 质量门禁

- 55 项自动测试覆盖智能规则、动态匹配、CRUD、排序、迁移和备份恢复。
- TypeScript/Vite 构建通过，依赖安全审计为 0 个已知漏洞。
- 10,003 个本地片段的 30 次检索基准 p95 为 75 ms，低于 250 ms 门禁。
- 浏览器端完成规则创建、编辑、动态筛选、计数和视觉验收。
- x64 Mac 真机使用旧版资料库完成 0.17 升级：旧文章与高亮保留，鼠标拖放成功写入资料夹，智能规则在应用重启后仍能返回正确内容。

## 已知边界

- 当前通用 Mac 安装包仍为 ad-hoc 签名、未公证版本。
- HTML5 拖放需要鼠标或触控板；键盘用户仍可使用现有批量“移动到…”控件完成相同操作。
- Apple Silicon 切片完成结构验证，但仍需 Apple Silicon 真机运行和 Gatekeeper 验收。
