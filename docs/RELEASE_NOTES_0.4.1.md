# Reader 0.4.1

本版本修复微信公众号链接被保存为“环境异常”验证页的问题，并无损修复现有资料。

## 微信导入

- 使用浏览器兼容请求头访问微信公众号文章，并以专用解析器读取账号、作者、标题、正文和延迟加载图片。
- 微信环境验证页会被识别并拒绝，失败任务保留明确错误和重试入口，不再污染资料库。
- 旧验证页记录会在启动时恢复为原始文章 URL；同一 URL 的重复失败记录只归档、不删除。
- 重新导入会原地更新文章，旧验证页作为版本历史保留，正确正文成为新版本。
- 微信图片复用现有 SSRF、跳转、MIME、文件签名、大小限制和 SHA-256 去重流程，阅读时使用本地附件。

## 真实链接验收

- 腾讯技术工程文章：正确提取标题、公众号、作者和正文，本地保存 4 个唯一图片附件，文章历史为 2 个版本。
- 麦肯锡文章：自动修复旧验证页，正确提取正文并本地保存 11 个唯一图片附件，文章历史为 2 个版本。

## 质量门禁

- `npm audit --audit-level=moderate`：0 个已知漏洞。
- `npm test`：20 项测试全部通过。
- `npm run build`：TypeScript 与生产构建通过。
