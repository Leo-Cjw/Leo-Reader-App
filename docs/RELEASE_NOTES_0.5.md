# Reader 0.5.0

本版本把“本地保存”继续推进为“可以安全带走、可以快速浏览”。

## 口令加密备份

- 数据安全中心默认提供口令加密备份，生成 `.readerbackup.enc`；原有 `.readerbackup.zip` 明文格式继续兼容。
- 使用 scrypt（N=65536、r=8、p=1）从至少 12 字符的口令派生 256 位密钥，再用 AES-256-GCM 对包含 SQLite、附件和清单的完整 ZIP 进行认证加密。
- salt 与 IV 每份备份随机生成；格式头参与认证。错误口令或密文任意字节被修改，恢复都会在解压前失败。
- Reader 不保存口令。解密明文只存在于权限受限的随机暂存目录，验证后立即删除。
- 恢复仍保留原有的路径、压缩体积、附件 SHA-256、数据库 SHA-256 与 SQLite `integrity_check`，并在应用数据前创建恢复前安全备份。

## 本地媒体缩略图

- 图片和 PDF 首次进入列表时在本机生成 640×360 WebP 缩略图，并按附件内容哈希缓存和复用。
- PDF 使用 PDF.js 安全渲染第一页；图片限制解码像素；并发请求共享同一个生成任务。
- 视频通过支持 Range 的本地附件端点由 WebKit 解码首帧，不上传也不额外转码。
- 缩略图为可再生缓存，不进入备份；恢复资料库时自动清空。

## 界面

- 文章列表为网页主图、本地图片、PDF 和视频增加紧凑预览，不牺牲标题、来源和分类信息。
- 数据安全中心明确区分加密/明文备份，提供口令确认、遗忘警告和加密恢复输入。

## 质量门禁

- 23 项自动测试覆盖明文与加密备份、错误口令、密文篡改、完整恢复、图片/PDF 缩略图缓存、HTTP 端点及既有导入/编辑链路。
- `npm audit --audit-level=moderate`、`npm test` 与 `npm run build` 必须全部通过后发布。
