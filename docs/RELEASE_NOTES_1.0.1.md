# Reader 1.0.1 Candidate

Reader 1.0.1 是不改变资料库结构的修复发行候选。SQLite schema 继续为 v12，`settings.json` 继续为 version 1；现有文章、附件、高亮、版本历史、资料夹、订阅与备份保持兼容。

## 微信文章导入

- 微信专用解析器升级为 v2：嵌套 HTML 表格转换为合法的 GFM 表格，`<pre>` 内用 `<br>` 表示的换行恢复为多行代码块。
- 正文已有图片时不再额外导入 Open Graph 封面；重导旧版微信文章会保留文章 ID、资料夹、标签和版本历史，只追加新的正文版本。旧的重复封面附件不会物理删除，以免破坏历史引用，但不会再出现在阅读器中。
- 已用真实微信文章完成视觉回归：8 个表格与 16 个代码块均正确渲染，3 张正文图片继续保存到本机。

## 网络与界面

- macOS 在确认 `utun*` 隧道路由后，可安全兼容 HTTPS 公众号等公开域名被透明代理映射到 `198.18.0.0/15` Fake-IP 的情况；直接 IP、HTTP、混合解析与非隧道私有地址仍被拒绝。
- 开发服务器代理重写浏览器 `Origin` 为本地 API origin，保持回环 API 的跨站请求防护，同时使本机开发导入流程可用。
- 侧栏和 macOS 打包图标切换为新的 Reader 标识。

## 版本与验证

- 主 App、Share Extension 和 Spotlight helper 统一为营销版本 `1.0.1`、构建号 `101`。
- 169/169 项自动测试通过，TypeScript/Vite 生产构建通过；新增回归覆盖微信表格、代码块、旧版原位升级、重复封面隐藏、透明代理 Fake-IP 边界与 URL 导入错误映射。
