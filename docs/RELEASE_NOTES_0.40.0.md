# Reader 0.40.0

本版本为 RSS、YouTube、X 与微博的自动订阅调度增加隐私安全的 macOS 系统通知。订阅通知使用独立、默认关闭的开关，只在后台自动批次确有新增或失败时显示聚合数量；手动“立即同步”保持安静。SQLite schema 仍为 v10，文章、附件、备份与导入导出格式不变。

## 后台订阅通知

- 设置中新增“后台订阅通知”，与既有“后台导入通知”分别控制。旧版设置缺失新字段、字段类型错误或文件读取失败时都保持关闭；修改任一开关不会改变另一项。
- 调度器只在一轮到期来源结束后汇总新增内容数与失败来源数。全部来源均无新内容且无失败时不显示通知，Reader 内任一主窗口或专注窗口位于前台时也不显示。
- 手动“立即同步”不经过通知批次回调，不会因为用户正在内容来源中操作而再次发出系统通知。
- 点击订阅通知会聚焦 Reader 并打开“内容来源”；主窗口已关闭时按既有安全配置重建。渲染器只新增固定 `sources` 单向命令，不获得任意 IPC 或窗口能力。

## 隐私与可靠性

- 服务端回调只包含 `{ imported, failed }`。来源标题、账号、URL、文章标题、正文、错误文本、来源/文章 ID、路径、堆栈和凭据都不进入通知控制器。
- 主进程使用固定中文模板，并把显示计数限制在 0–99。通知失败、系统不支持或权限被拒绝不会影响同步结果，也不会降级成网页通知。
- 一轮中的单个来源失败仍按既有退避策略处理，其他到期来源继续同步；通知回调自身失败不会中断调度器。
- 0.38 的后台导入通知行为与设置值保持兼容。
