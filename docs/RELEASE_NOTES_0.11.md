# Reader 0.11.0

本版本补齐 AI 工作台的运行时配置与凭据边界：不改环境变量、不重启服务，也能安全切换本地与远程处理。

## AI 设置与即时生效

- 标题栏新增“设置”，集中展示本地/远程状态、凭据后端、配置来源与最近更新时间。
- 可启用或关闭远程 AI、编辑 Reader Gateway 地址、保存或移除 API 密钥；保存后摘要、对话、翻译和跨文章创作立即刷新能力状态。
- “恢复默认”会移除 Reader 保存的 Keychain 密钥，并重新采用环境变量默认值；没有环境变量时回到完全本地模式。

## Keychain 与不泄密设计

- macOS API 密钥使用独立的系统 Keychain 通用密码项保存，调用 `/usr/bin/security` 时不经 shell，密钥通过标准输入传递。
- `data/settings.json` 只保存启用状态、规范化端点和是否存在密钥，文件权限为 `0600`；密钥不进入 SQLite、备份、导出或任何设置 API 响应。
- Keychain 写入与设置文件保存采用补偿回滚；配置保存失败不会留下半完成的凭据状态。

## 安全端点与连接测试

- 非本机服务必须使用 HTTPS；HTTP 只允许 `localhost`、`127.0.0.1` 和 `::1`。
- 拒绝端点 URL 中的用户名、密码、片段，以及看似 API key、token、secret 或签名的查询参数。
- 连接测试使用候选设置创建一次性客户端，只发送 Reader 内置测试文本，不读取或发送资料库内容。
- 修复设置开关的原生 checkbox 点击/焦点范围，使鼠标、键盘和辅助技术共享同一真实控件。
