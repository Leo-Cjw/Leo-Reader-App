# Reader 0.9.0

本版本把 Markdown 从“能编辑文本”推进到完整的本地图文写作工作台。

## 文章图片

- 在任意文章编辑器中选择或拖入多张 PNG、JPEG、WebP、GIF、AVIF、HEIC 图片。
- 图片直接挂在当前文章，不会额外创建一条独立图片内容；上传成功后自动插入当前光标位置。
- 顶部资源带显示文章已有图片，点击即可再次插入；阅读页会识别正文引用，避免重复显示为独立附件。
- 每张图片最多 20 MB，服务端同时检查 MIME 和文件签名，伪造图片会被拒绝并清理暂存文件。
- SHA-256 用于稳定存储和去重：同一文章重复上传复用附件，全资料库相同字节只保存一份磁盘文件。

## 自动保存

- 标题、摘要、作者、来源和 Markdown 正文停止输入 1.4 秒后自动写入本地 SQLite。
- 编辑器状态明确显示等待、正在保存、保存时间或失败，不用依赖模糊的“已同步”提示。
- 手动“保存并关闭”仍然保留；关闭未保存内容前会明确确认。
- 正文变化继续进入版本历史，自动保存产生的内容也能恢复。

## 数据与质量

- 保持 Schema v4，无破坏性迁移；现有 0.8 资料库可直接升级。
- 32 项自动测试覆盖编辑器图片签名、原始字节、去重、暂存清理、正文插入与版本历史，以及全部既有主链路。
- 发布门禁为 `npm audit --audit-level=moderate`、`npm test` 和 `npm run build`。

## 尚未包含
