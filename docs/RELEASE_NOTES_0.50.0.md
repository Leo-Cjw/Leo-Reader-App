# Reader 0.50.0

本版本补齐本地语义检索的模型选型提示与近邻召回边界。功能仍默认关闭，schema 保持 v12，不改变文章、附件、设置或既有向量格式。

## 内置中英文质量探针

- “测试本地模型”和启用流程现在一次发送 9 句 Reader 固定短句，组成中文、英文与跨语言三组 anchor/positive/negative，不读取资料库标题、正文、摘要、来源、标签或附件。
- Reader 在本机计算每组正样本与负样本的余弦 margin，只向设置界面返回通过数、总数、平均 margin 和 `strong/partial/poor` 聚合等级。
- 探针结果用于提示模型选型，不上传、不写入设置、SQLite、备份、导出或日志，也不会擅自阻止用户选择特定模型。
- 设置界面显示维度、三组探针通过数和有限质量提示；索引、远程生成服务和 Keychain 边界保持彼此独立。
- 当前构建机没有安装 Ollama，因此本版本不声明 `embeddinggemma` 或其他真实模型的质量分数；真实中英文资料集基准仍需在安装模型的机器上继续扩充。

## 低置信位多探针召回

- 每个查询向量仍计算 16 个 8-bit 稀疏随机投影桶；0.50 额外按每个 band 的投影绝对值选择两个最低置信位，分别翻转后与精确桶组成三个互异候选桶。
- SQLite 只读取同一模型、活动文章与这 48 个有限桶命中的候选，候选总数继续硬限制为 1,500。
- 邻桶命中只用于候选生成；最终相关性仍由完整单位向量的精确余弦、精确桶/探针命中稳定排序和既有 reciprocal-rank fusion 决定。
- 确定性 200 对近邻回归集要求多探针召回严格高于精确桶并达到 200/200，避免实现退化成只扩大 SQL 而没有实际召回收益。

## 验证

- 140/140 项自动测试通过。新增覆盖三组质量计算、强/弱模型聚合、9 句固定探针、中英输入、每 band 三个互异桶、单 bit 邻桶和 200 对近邻召回。
- 10,003 片段、30 轮查询性能门禁：词法检索 p50 21.80 ms、p95 25.84 ms；三桶多探针 LSH 候选与精确余弦 p50 133.02 ms、p95 144.93 ms，均低于 250 ms 门槛。
- 生产构建和依赖审计通过；生产依赖为 0 个已知漏洞，构建树只保留既有、精确评估的 Electron Universal 公告例外。
- Universal x64/arm64 合并、签名回读、14 个顶层模态框 AX、Share 文本/文件/取消/URL、冻结 0.43 schema v11 资料库升级到 schema v12、继续写入、重启、SQLite 完整性和附件 SHA-256 仍作为阻断门禁。
