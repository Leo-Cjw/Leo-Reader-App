# Reader 0.32.0

本版本把不受信任网页、PDF 和图片/PDF 缩略图的复杂解析移出长期运行的本地服务进程。资料库 schema 仍为 v10，API、文章、附件、缩略图缓存键、导入队列、备份与 Markdown 往返格式均保持兼容。

## 一次性解析进程

- URL 获取继续在父进程执行既有 DNS 全量解析、固定公网地址连接、重定向复检、15 秒网络超时和 4 MB 解压后正文限制；获取完成后，DOM、Mozilla Readability、Turndown 与微信公众号专用解析才进入子进程。
- PDF.js 文本抽取以及图片/PDF 的 640×360 WebP 生成进入同一受控执行入口。父进程仍独占数据库、持久化队列、附件最终落盘和缓存原子改名。
- 每个任务使用一次性子进程。解析器崩溃、超时、内存异常或协议错误不会终止本地 HTTP 服务；持久化导入任务进入既有失败状态，可由用户重试。

## 权限与资源边界

- 子进程使用当前 Node 或打包 Electron 可执行文件的 Node 模式，V8 heap 固定为 256 MB；网页任务最多 15 秒，PDF 与缩略图任务最多 30 秒。
- IPC 输入和输出各限 12 MB，缩略图解码结果另限 2 MB，并重新校验为 WebP。全局最多两个解析器并发、32 个等待任务，超限返回 503 而不是继续创建进程。
- 解析器不继承父进程环境，只保留语言、时区和临时目录；Reader 或第三方密钥环境变量不会跨过进程边界。
- [Node permission model](https://nodejs.org/api/permissions.html)只允许读取应用代码和当前明确的源文件，拒绝文件写入、任意系统文件读取和嵌套子进程。响应以每次随机 nonce 定界，依赖库 stdout 不能伪造有效结果。
- 图片缩略图需要项目自带的原生 Canvas addon，因此只有该任务额外启用受信任 addon。该设计提供 Node 权限收缩、资源上限与进程崩溃隔离，但不宣称是完整的 macOS syscall 或网络沙箱。

## 兼容性

- 网页文章字段、正文 Markdown、图片令牌、本地化状态与既有提取器版本不变。
- PDF 仍最多抽取 250 页和 1,000,000 字；原文件、内容哈希、确定性文章 ID 和全文/RAG 索引行为不变。
- 图片/PDF 缩略图仍使用既有内容哈希缓存名；缓存命中不会启动新进程。视频仍由同源本地媒体端点交给 Chromium 解码，不进入新的静态解析器。
- 本版本不修改 SQLite schema、迁移注册表、用户数据目录或备份清单。

## 自动验证

- 98/98 项自动测试通过，生产构建通过；`npm audit --audit-level=low` 为 0 漏洞。
- 新增运行时测试确认独立 PID、256 MB V8 heap、最小环境、任意文件读取/写入与嵌套进程拒绝、网页抽取兼容、PDF 文本、图片/PDF 缩略图、并发与队列上限。
- 超时、异常退出、输入超限和输出超限均故障闭锁；同一父服务随后可继续启动并完成新的解析任务。
- macOS `/tmp` 到 `/private/tmp` 的真实路径规范化有独立回归，permission model 始终授权最终解析路径而不是符号链接别名。
- 66,280 B 网页、15 次一次性进程基准：p50 322.15 ms、p95 364.32 ms；解析位于持久化后台导入队列，不阻塞资料库浏览。

## 已知边界

- Node permission model 不是完整 OS 沙箱；允许的原生 Canvas addon 如果自身发生原生代码漏洞，Node 级权限不能提供同等约束。一次性进程仍可把崩溃与多数资源故障隔离出主服务。
- 当前本地包仍缺少真实 Apple Developer ID、公证凭据、正式 GitHub Release 与 Apple Silicon 真机 Gatekeeper/跨版本升级验收；ad-hoc 包不会连接自动更新服务。
- 最终包原生 AX 复验与启用 VoiceOver 的完整人工听读仍是正式发行门禁。
