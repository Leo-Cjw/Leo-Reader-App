# Reader 0.26.0

本版本完成 Markdown 编辑器保存流程和高亮批注管理的键盘/读屏反馈。文章、附件、高亮和数据库结构均未变化，API 不变，schema 保持 v10。

## Markdown 编辑器

- 打开编辑器后焦点直接进入标题，而不是停在关闭按钮。
- ⌘S 和 Ctrl+S 调用与自动保存、保存按钮相同的本地写入路径，不关闭窗口；底部保留明确的“保存”操作。
- “等待保存、正在保存、已保存、保存失败”通过 `role=status` 播报；手动与自动保存统一使用准确的中性文案。
- Markdown 源码和实时预览是独立具名 region，读屏可快速识别两栏。
- 图片上传输入拥有明确名称，键盘焦点落在完整可见标签上，并显示强调色焦点框；已有图片按钮说明将插入哪一个本地文件。
- Escape 继续复用 0.24 的安全关闭路径：忙碌时禁用，未保存时保留确认，关闭后回到“编辑”按钮。

## 高亮与批注

- 工具栏“高亮”会滚动并把焦点移到具名批注 region，而不是只改变视口。
- 正文成为可聚焦的具名区域，为平台文本选择和焦点恢复提供稳定落点。
- 当前颜色使用 `aria-pressed`，颜色组、删除按钮和批注输入均带具体高亮序号。
- 定位原文、改变颜色和批注失焦写回会通过隐藏 live region 播报结果。
- 保存高亮浮层使用标题和选中文字描述；文档级 Escape 在浮层任意焦点位置都可关闭，并把焦点还给选区发起处。

- 真实界面验证编辑器初始焦点、具名两栏、⌘S 写库、保存播报、Escape 关闭和焦点恢复。

## 已知边界

- 静态正文的纯键盘原生选区仍取决于 macOS、浏览器 caret browsing 或 VoiceOver 文本交互；本轮没有另造一套选区编辑器。
