# Reader 0.46.0

本版本把“全部顶层模态框都能可靠地被键盘和辅助技术使用”从代码声明提升为每次 macOS 发行的最终包阻断门禁。SQLite schema 保持 v11；文章、附件、设置、备份和 Markdown 导入导出格式均与 0.45.0 兼容。

## 全部模态框门禁

- 最终 Universal App 现在逐个验证全部 14 个顶层模态框，而不再只覆盖八个核心窗口。
- 新增覆盖 Markdown 编辑器、版本历史、批量二次创作、导出资料包、社交连接器和本地运行日志；原有设置、添加内容、订阅、普通/智能资料夹、重复治理、导入队列和数据安全继续执行。
- 批量创作与导出通过真实“选择已加载内容”状态进入；社交连接器和本地日志分别通过“订阅管理→连接器”“数据安全中心→本地日志”跨窗口路径进入。
- 每个窗口都必须具有准确名称，移除背景 AX 主内容，没有无名交互控件，让焦点进入窗口，保持 Tab 闭环，响应 Escape，并把焦点还给主界面原入口。

## 焦点恢复可靠性

- 模态焦点管理在首帧前安装，避免界面刚出现即可操作时错过入口焦点。
- 首个窗口出现时同时核对当前真实焦点和最近的外部激活控件，不把浏览器节点切换期间产生的 `body` 当作恢复目标。
- 对话框切换仍保留最初的主界面入口，因此关闭社交连接器或本地日志后不会尝试聚焦已经卸载的中间窗口按钮。
- 阅读器的“编辑文章”“查看版本历史”及批量“创作/导出”入口增加稳定且明确的可访问名称。

## 验证

- `npm test`：125/125 通过；`npm run build`：生产构建通过；`npm run audit:dependencies`：生产依赖 0 个已知漏洞。
- 最终 0.46 Universal 候选的 14 个顶层模态框闭环全部通过，全部暴露交互控件均有名称。
- 最终候选 Share 门禁通过：文本字节受限、确认前写入为 0、Markdown 精确持久化、URL 回归通过。
- 最终候选从 0.43.0 schema v11 基准完成读取、写入、退出、重启与完整性闭环；附件 SHA-256 保持不变。
- 主程序、Spotlight Helper 与 Share Extension 均包含 x86_64/arm64，各自严格签名和 `hdiutil verify` 通过。

## 已知边界

- Chromium AX 自动化不能替代正式签名包的 AppKit 外层复验或启用 VoiceOver 后的完整人工听读。
- 当前 ad-hoc 包不证明 Developer ID、Gatekeeper、公证、系统通知、Spotlight/Share Extension 系统入口和 `autoUpdater` 端到端安装。
- 文件、图片和视频分享仍需要安全作用域或共享容器生命周期设计。
