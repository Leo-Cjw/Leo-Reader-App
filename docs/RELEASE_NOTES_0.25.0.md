# Reader 0.25.0

本版本把侧栏资料夹从视觉缩进列表升级为可折叠、可完整键盘操作的语义树。资料夹、文章和数据库结构均未变化，API 不变，schema 保持 v10。

## 资料夹键盘树

- 资料夹容器使用 `tree`，每一行使用单一原生按钮 `treeitem`，不会引入嵌套交互控件。
- 每行公开真实层级、同级位置与数量、展开状态和选中状态；折叠子树不会把隐藏行留在 Tab 顺序中。
- 树只保留一个 Tab 停靠点。上/下方向键移动到前后可见行，Home/End 跳到首尾。
- 右方向键先展开父资料夹，再进入第一个子资料夹；左方向键先折叠，再返回父资料夹。
- Enter 和 Space 复用既有资料夹选择路径；鼠标点击资料夹仍筛选内容，点击小箭头只折叠或展开。
- 可见键盘焦点使用现有强调色，折叠状态只保存在当前会话内，不写入数据库或备份。
- 文章拖放目标和移动回调保持不变。

## 自动与真实界面回归

- 新增资料夹树源码契约测试，固定树角色、层级属性、键位和 `:focus-visible` 样式。
- 使用独立临时数据库建立三级资料夹树，不读取或修改用户资料。
- 真实界面确认树只存在一个 `tabIndex=0`，根/子/孙节点分别公开 level 1/2/3。
- 已验证 ArrowUp/Down、ArrowLeft/Right、Home/End、Enter、Space、鼠标折叠、选中态和可见焦点。
- 折叠“人工智能”会隐藏“模型评测”；再次展开后可以进入子节点并用键盘选择。
- 隔离测试服务和浏览器标签页均已关闭，仓库 `data/` 与用户资料未被测试写入。
