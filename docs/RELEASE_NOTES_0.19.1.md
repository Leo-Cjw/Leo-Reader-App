# Reader 0.19.1

本版本为数据安全维护版：Reader 可以在严格门禁下修复可重建的本地权限和搜索索引，同时明确拒绝猜测性修改用户内容。

## 受控修复

- 数据安全中心会根据最近一次资料库体检显示“安全修复”入口，并在执行前要求用户确认。
- 只允许两类可重建动作：把数据目录、SQLite 数据库及 sidecar 收紧到当前用户权限；从文章权威记录重建全文 FTS、RAG 分块和分块 FTS。
- 索引重建前自动创建包含 SQLite、附件和 SHA-256 清单的完整 `pre-repair` 备份，完成后重新执行全套健康检查。
- 修复单实例运行；存在导入任务、待重启恢复或另一项修复时拒绝开始。
- schema 仍为 v9，0.19.0 用户升级不需要数据库迁移。

## 失败闭锁与隐私

- SQLite 页结构、外键、迁移审计或附件对账存在错误时，自动修复入口关闭并引导使用可靠备份恢复。
- 不自动修复数据库页、猜测外键、伪造缺失附件、删除未引用文件，也不更新正文、版本、高亮、标签、阅读状态或附件记录。
- 索引重建失败时，修复前完整备份仍保留，可从数据安全中心下载。
- 修复 API 只返回动作名、脱敏健康汇总和公开备份元数据；不返回正文、附件名、存储名、记录 ID、备份 manifest 或磁盘路径。

## 质量门禁

- 70 项自动测试全部通过。新增故障注入覆盖权限与索引修复、修复前备份、核心问题闭锁、重建失败安全性、文章记录/附件字节不变性、API 脱敏和备份下载。
- TypeScript/Vite 生产构建通过，依赖审计为 0 个已知漏洞。
- 10,003 个本地片段、30 次查询的检索基准 p50 为 25.38 ms、p95 为 28.23 ms，低于 250 ms 门禁。
- Universal App 检出 x86_64 与 arm64 双架构，版本元数据为 0.19.1，ad-hoc 深度签名验证通过；DMG 通过 `hdiutil verify`。
- `Reader-0.19.1-universal.dmg` 大小为 255,540,632 字节，SHA-256 为 `bece4ef57c02ff551351ab8ce142ae9881c2fa688f41bd5aad64b5c82745cb24`。

## 已知边界

- 自动修复只覆盖可从权威数据重建的权限和检索索引，不是通用 SQLite 修复器。
- 迁移快照目前可查看和导出，但还没有面向用户的一键回滚流程。
- Developer ID 正式签名、Apple 公证、自动更新和双架构真机安装升级验收仍未完成。
