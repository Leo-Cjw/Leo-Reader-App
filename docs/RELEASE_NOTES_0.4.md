# Reader 0.4.0

本版本把 URL 导入从“抓到一段文字”升级为“真正离线可读”。

## 新能力

- 使用 Mozilla Readability 去除导航、推荐和页面噪声，保留正文标题、作者、摘要与结构。
- 将抽取结果转换为 GFM Markdown，保留标题、列表、引用、表格、代码块、链接与图片语义。
- 代表图片和正文图片通过 SSRF、重定向、超时、MIME、文件签名与体积校验后保存到本机。
- 图片按 SHA-256 去重；正文 Markdown 改写为同源本地附件 URL，首个文章版本只保存最终内容。
- 阅读页显示“离线完整 / 部分离线 / 仅正文离线”，并用本地主图、正文图片和图注呈现资源。
- 图片失败时降级为显式在线链接，不让阅读器自动向第三方图片服务器发起请求。

## 资源边界

- 网页正文最大 4 MB。
- 单张远程图片最大 12 MB。
- 单篇最多本地化 16 张正文图片，本地化预算 48 MB。
- 超出边界或下载失败不会阻塞正文导入，错误会写入文章元数据。

## 质量门禁

- `npm audit --audit-level=high`：0 个已知漏洞。
- `npm test`：17 项测试全部通过，新增 Readability/GFM、正文图片去重、本地 URL 改写、失败降级与基线版本一致性覆盖。
- `npm run build`：TypeScript 与生产构建通过。

## 已知边界

- 旧版本已导入文章不会自动重新抓取；界面会标记为“正文在本机”。
- 图片、视频和 PDF 缩略图仍在后续 M2 范围。
- 备份尚未加密；当前应依赖 FileVault 或受信任的加密磁盘。
- 原生签名、公证、App Sandbox、Keychain 和 Share Extension 需要完整 Xcode 工具链，属于 M3。
