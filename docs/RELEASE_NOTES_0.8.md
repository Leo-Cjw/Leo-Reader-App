# Reader 0.8.0

本版本让本地资料不仅安全保存，也能从 Reader 中完整带走，并开始治理长期积累产生的重复内容。

## 可迁移 Markdown 资料包

- 内容列表多选后可直接导出 ZIP，文章是带 frontmatter 的普通 Markdown，可在文件系统或其他知识库工具中继续使用。
- 可选携带原始 PDF、图片、视频和其他附件；正文里的 Reader 私有资源链接自动改写为相对路径。
- 每个资料包附带 `manifest.json`，记录原链接、标签、目录、附件大小与 SHA-256；导出不改变本地内容状态。
- 服务端以流式 ZIP 输出，单次限制 500 条，并严格拒绝附件路径越界或文件缺失。

## 可逆重复内容治理

- 新增资料库“查重”，按规范化原始 URL、完整正文以及标题摘要识别高置信重复组。
- 处理前明确对照每个版本并选择保留项；Reader 不会静默自动删除。
- 标签、收藏、最长摘要和阅读进度会合并到保留版本，其余副本只移入归档，正文、历史和附件仍保存在本机。
- 误判后可在归档视图恢复副本。整个合并操作使用单一 SQLite 事务。

## 数据与质量

- 保持 Schema v4，无破坏性迁移；现有 0.7 资料库可直接升级。
- 31 项自动测试覆盖 Markdown ZIP 结构、附件原始字节、manifest、重复检测和状态合并，以及全部既有主链路。
- 发布门禁保持为 `npm audit --audit-level=moderate`、`npm test` 和 `npm run build`。
