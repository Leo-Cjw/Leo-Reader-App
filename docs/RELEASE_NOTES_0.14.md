# Reader 0.14.0

本版本补齐 X 与微博的可持续官方连接方式，把四类订阅统一为可观察、可退避、可本地化的后台采集系统。

## 官方社交连接器

- X 使用官方 API 的用户查询与用户动态端点；首次同步读取最近内容，后续使用 `since_id` 增量分页。
- X Bearer Token 单独写入 macOS Keychain，不进入 SQLite、设置文件、OPML、备份、导出或 API 响应；支持候选凭据测试与明确撤销。
- 微博调用开放平台官方 `@weibo-ai/weibo-cli`。OAuth 登录与系统 Keychain 由 CLI 管理，Reader 不读取或复制令牌。
- X 用户名和微博数字 UID 会规范为稳定主页地址；单条动态、搜索页及非官方域名会被拒绝。

## 同步与本地阅读

- Schema v6 为来源增加平台用户 ID、同步游标、配额剩余和限流重置时间；现有资料库幂等升级。
- 四类来源共用单实例调度、失败退避、手动同步与健康状态。X 配额耗尽时不会在重置前反复请求。
- 社交正文、来源回链、互动元数据和图片都写入本地；图片复用现有 SSRF、签名、大小限制与 SHA-256 去重流程。
- OPML 可往返保存 X/微博来源类型、启用状态和频率，但绝不携带凭据。

## 界面

- “添加 → 自动订阅”新增 X 用户与微博用户，可直接跳转到社交连接器设置。
- 连接器设置集中展示凭据边界、官方安装/登录命令、连接测试与撤销操作。
- 订阅中心显示四类来源、X 剩余配额、错误和下次同步状态；断开连接器不会删除既有文章。

## 质量门禁

- 49 项自动测试通过，新增 URL 规范化、平台负载转换、游标推进、官方 CLI 参数、Schema v6、限流状态、Keychain 边界与 HTTP 端到端覆盖。
- `npm run build` 与 `npm audit --audit-level=moderate` 通过后生成 Intel Mac ad-hoc 签名包。

## 已知边界

- X Developer 访问层级、速率和费用由 X 平台决定；Reader 不代理或绕过平台权限。
- 微博连接器要求用户先安装并登录官方 CLI。
- 当前安装包仍是 Intel x64、ad-hoc 签名且未公证；Developer ID、公证与通用架构分发仍是发布前工作。
