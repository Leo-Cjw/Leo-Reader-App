# Reader 0.20.1

本版本收紧 Reader 的网页采集网络边界：URL、订阅与远程图片的实际连接现在固定到已经验证的公网 IP，关闭 DNS 校验与连接之间的 rebinding 窗口。schema 仍为 v9，0.20.0 用户升级不需要数据库迁移。

## 固定地址网络传输

- 每一跳解析域名的全部地址；只要其中包含环回、局域网、链路本地、CGNAT、IPv6 ULA 或其他保留地址，就拒绝整次请求。
- URL 不再接受嵌入式用户名或密码，避免凭据混入导入来源。
- TCP 连接只使用本次已验证的具体 IP；HTTP Host、TLS SNI 与证书校验仍使用原始域名。
- 每次重定向重新执行 DNS 解析、地址校验与连接绑定，不复用上一跳的结果。
- 禁用跨请求连接复用，避免连接池跨越独立安全判断。

## 响应边界

- 15 秒超时现在覆盖 DNS 之后的连接、响应头和完整响应体读取，而不是只覆盖响应头。
- 支持 gzip、deflate 与 Brotli，并在解压后执行 4 MB 网页/RSS 或 12 MB 图片上限。
- 多个已验证公网地址可以在连接建立失败时依次尝试；收到响应后发生的格式、解压或体积错误不会换地址重复下载。
- 现有图片 MIME 与文件签名校验、五跳重定向上限和正文抽取逻辑保持不变。

## 质量门禁

- 77 项自动测试全部通过；新增覆盖 CGNAT/保留网段、完整 IPv6 链路本地范围、混合公网/私网 DNS 拒绝、固定 lookup、TLS 域名身份、gzip 解压、全响应体体积限制和超时。
- 真实公网 IP 的 HTTPS 全响应读取冒烟通过；域名与重定向安全路径由可注入解析和传输测试覆盖。
- TypeScript/Vite 生产构建通过，依赖审计为 0 个已知漏洞。
- 10,003 个本地片段、30 次查询的检索基准 p50 为 24.92 ms、p95 为 26.28 ms，低于 250 ms 门禁。
- Universal App 检出 x86_64 与 arm64 双架构，版本元数据为 0.20.1，ad-hoc 深度签名验证通过；DMG 通过 `hdiutil verify`。
- `Reader-0.20.1-universal.dmg` 大小为 255,456,127 字节，SHA-256 为 `bb0acef2d9642bf626fe5f916eb7ee7ee4f5164d4c41d64269b7fc24e754adf6`。

## 已知边界

- HTML、PDF 与媒体元数据解析仍在主本地服务进程内；后续仍需迁移到资源受限的隔离进程。
- 把公网域名映射到 `198.18.0.0/15` 等保留网段的 fake-IP 代理会被安全边界拒绝；后续需要显式、可审计的代理支持，而不是放宽 SSRF 校验。
- Developer ID 正式签名、Apple 公证、自动更新和双架构真机安装升级验收仍未完成。
