# 成熟产品路线图

## 当前基线：Reader for Mac 0.30.0

已完成可运行的 local-first 主链路：本地 SQLite、数据迁移、正文高亮与批注、文章/目录/标签、收藏与阅读状态、URL/RSS/YouTube/X/微博/Markdown 采集、全文搜索、阅读器、明暗主题和 AI 适配器。0.30.0 把五条文件导入路径统一为可见、可聚焦的系统文件选择按钮，并修复打包 App 内容已加载但窗口可能不显示的问题；0.29.0 完成静态正文只读键盘 Range 选取与可播报保存链路；0.28.0 完成只对 Developer ID 正式发行包开放的应用内自动更新与可验证 universal 更新 ZIP；0.27.0 完成系统状态下的后台调度；0.26.0 完成编辑器与批注状态播报；0.25.0 补齐侧栏资料夹树键盘；0.24.0 建立顶层模态焦点契约；0.23.0 拆分列表摘要与文章详情；0.22.0 完成十万条资料库性能门禁。92 项自动测试覆盖文件选择器边界、更新签名门禁、键盘选区静态契约、后台状态合并、编辑器/批注与键盘树、摘要/详情边界、分页、索引体检/修复、迁移快照与故障闭锁、固定地址传输、日志隐私、Markdown 往返、迁移审计、连接器、桌面壳、发行工具及全部产品主链路。

- [已完成] 双栏 Markdown 编辑器、安全实时预览与任意文章编辑。
- [已完成] Readability 级正文抽取、GFM 转换、代表图片与正文内嵌图片本地化、离线完整度标识。
- [已完成] 图片、视频和 PDF 的本地缩略图/首帧预览。
- [已完成] 图库视图与媒体筛选。
- [已完成] RSS/Atom 定时同步、ETag/Last-Modified、失败退避、OPML 导入导出与 YouTube RSS 首批接入。
- [已完成] 任意文章的内容版本历史、预览与可逆恢复。
- [已完成] 正文选区高亮、四种颜色、批注编辑、原文定位、本地持久化、备份恢复与 Markdown 导出。
- [已完成] Markdown 图片资源管理、多图上传/拖入、光标插入和自动保存。
- [已完成] 标签批量操作、树形目录 CRUD、子树聚合与安全删除。
- [已完成] 高置信重复内容检测、状态合并与可恢复副本归档。
- [已完成] 规则驱动智能资料夹、动态计数、智能视图排序、同级资料夹排序，以及文章从列表直接拖放到资料夹。

验收标准：所有导入任务可暂停、重试、追踪错误；应用离线重启后任务状态不丢失。

## M3：原生 macOS 发行

- [部分完成] Electron 外壳、单实例、原生窗口/菜单、Dock 生命周期、系统另存为，以及附件、编辑器图片、Reader ZIP、OPML 与备份恢复的系统文件选择器均已完成；Share Extension 仍待实现。
- [部分完成] 渲染器沙箱、CSP、权限拒绝、Keychain、通用架构、ad-hoc 签名、DMG，以及只允许 Developer ID 正式包使用的自动更新均已完成；hardened runtime、App/DMG 公证和可验证更新 ZIP 流水线已接入，仍需真实证书、公证凭据、正式 GitHub Release 与 Apple Silicon 真机升级验收。
- [部分完成] 应用快捷键和菜单命令已完成；Spotlight、通知与多窗口仍待实现。
- [已完成] 睡眠/唤醒、离线恢复、电池电量不高于 20% 与系统严重热/降频状态下的后台调度策略；待恢复锁和系统条件不会互相绕过。

验收标准：全新 Mac 可安装、首次启动可用、升级不丢数据，并通过 Gatekeeper。

## M4：AI 阅读工作台

- [部分完成] 可配置兼容 Reader action 契约的远程服务与回环本地模型，macOS 密钥进入 Keychain；提供商预设与模型目录仍待实现。
- [已完成] 单篇翻译、多资料结构化整理/远程创作，以及文章级来源回链。
- [部分完成] 确定性分块、增量词法索引与本地优先 RAG 已完成；可选本地嵌入、向量召回和混合重排仍待实现。
- [已完成] 每次派生结果保留模型、提示词版本、来源文章和用户编辑历史；对话回答提供段落级来源片段、原文偏移和可点击回链。

验收标准：回答可追溯到原文段落；未授权时不上传正文；用户能逐任务选择本地或远程处理。

## M5：订阅与连接器

- [已完成] YouTube 频道通过公开 Atom Feed 接入，不需要账号令牌。
- [已完成] RSS/YouTube 去重、条件请求、失败退避和来源健康度。
- [已完成] 可观测的同步中心：上次结果、上次错误、下次运行时间、开关与频率。
- [已完成] X 通过官方 API 接入，Bearer Token 保存到 Reader 独立 Keychain 项。
- [已完成] 微博通过开放平台官方 CLI 接入，Reader 不接触 CLI 管理的 OAuth Token。
- [已完成] 账号令牌生命周期、限流、增量游标、测试与撤销授权。

验收标准：连接器失效不会拖垮主应用；授权随时可撤销并能清理对应凭据。

## M6：可靠性与可选同步

- [已完成] 可验证完整备份、恢复前安全备份和启动时原子恢复。
- [已完成] scrypt + AES-256-GCM 口令加密备份、错误口令与篡改拒绝。
- [已完成] 选择性 Markdown/附件导出、相对资源链接与 SHA-256 manifest。
- [已完成] Reader Markdown ZIP 安全预检、逐篇选择、目标资料夹、ID/URL 冲突跳过、v3 无损往返与 v2 兼容导入。
- [已完成] schema 升级前一致性数据库快照、快照完整性校验、安全降级拒绝，以及数据安全中心中的快照查看和导出。
- [已完成] v8 不可变 bootstrap、逐版本事务迁移、固定名称与 SHA-256 审计，以及失败时结构/版本/审计原子回滚。
- [已完成] 只读资料库体检：SQLite 完整性、外键、迁移历史、本机权限、附件可用性和检索索引，并在 API/UI 中只返回脱敏汇总。
- [已完成] 权限收紧、全文/RAG 索引重建、修复前完整备份、核心故障闭锁和修复后复检，以及具备校验、当前完整备份、重启原子替换和重新迁移前提的迁移快照恢复。数据库结构、外键与附件不会自动猜测修复。
- 可选端到端加密多设备同步；本地单机模式继续作为默认。
- [部分完成] 10 万条内容的列表、筛选、检索、统计与长正文载荷门禁已完成；文章卡片、顶层模态框、侧栏资料夹树、Markdown 编辑器保存、高亮批注管理及静态正文只读 Range 选取具备明确的键盘/ARIA 契约。完整 VoiceOver 真机审计、国际化仍待推进。
- [部分完成] 可查看、导出和清除的隐私安全本地日志、有限轮转及意外错误脱敏已完成；产品不启用遥测。未来若提供匿名诊断，必须默认关闭并逐次获得明确同意。

验收标准：10 万条资料下搜索和列表交互保持可感知流畅；备份恢复演练能够通过自动化验证。

## 优先顺序

下一迭代建议取得 Apple Developer ID，运行已接入的 App/DMG 公证流水线，发布首个携带 universal 更新 ZIP 的正式 GitHub Release，并在 Intel 与 Apple Silicon 真机完成 Gatekeeper、0.30→后续版本自动升级及资料库不丢失验收。代码内优先完成 VoiceOver 专项审计；其后实现 Share Extension、国际化、可选本地嵌入与混合重排。
