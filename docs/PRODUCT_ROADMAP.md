# 成熟产品路线图

## 当前基线：Reader for Mac 0.41.0

已完成可运行的 local-first 主链路：本地 SQLite、数据迁移、正文高亮与批注、文章/目录/标签、收藏与阅读状态、URL/RSS/YouTube/X/微博/Markdown 采集、全文搜索、阅读器、明暗主题和 AI 适配器。0.41.0 增加默认关闭、受数据保护且可彻底删除的 macOS Spotlight 索引，使用 Universal Swift helper、持久化 revision outbox 与双重深链校验；0.40.0 增加独立 opt-in、仅自动批次触发且不暴露来源内容的后台订阅通知；此前迭代已完成专注窗口、导入通知、渲染器恢复、模态隔离、安全外部保存入口、辅助技术状态、后台控制与解析进程隔离。120 项自动测试覆盖 Spotlight 迁移/队列/重试/删除/深链/打包、通知、专注窗口、导入、恢复、模态与 AX、解析进程、更新门禁、搜索、迁移与全部产品主链路。

## M2：完整内容采集（进行中）

- [已完成] 用户可在队列窗口暂停或继续；偏好跨重启保持，当前任务完成后停止领取下一项，继续操作不能绕过资料恢复、睡眠或系统资源限制。
- [已完成] 双栏 Markdown 编辑器、安全实时预览与任意文章编辑。
- [已完成] Readability 级正文抽取、GFM 转换、代表图片与正文内嵌图片本地化、离线完整度标识。
- [已完成] 图片、视频和 PDF 的本地缩略图/首帧预览。
- [已完成] 图库视图与媒体筛选。
- [已完成] RSS/Atom 定时同步、ETag/Last-Modified、失败退避、OPML 导入导出与 YouTube RSS 首批接入。
- [已完成] 任意文章的内容版本历史、预览与可逆恢复。
- [已完成] 正文选区高亮、四种颜色、批注编辑、原文定位、本地持久化、备份恢复与 Markdown 导出。
- [已完成] Markdown 图片资源管理、多图上传/拖入、光标插入和自动保存。
- [已完成] 标签批量操作、树形目录 CRUD、子树聚合与安全删除。
- [已完成] 高置信重复内容检测、状态合并与可恢复副本归档。
- [已完成] 规则驱动智能资料夹、动态计数、智能视图排序、同级资料夹排序，以及文章从列表直接拖放到资料夹。
- [已完成] 网页抽取、PDF 文本解析与图片/PDF 缩略图解码使用一次性权限和资源受限进程；解析崩溃、超时或输出超限不会终止本地服务，导入任务仍可重试。

验收标准：所有导入任务可暂停、重试、追踪错误；应用离线重启后任务状态不丢失。

## M3：原生 macOS 发行

- [部分完成] Electron 外壳、单实例、原生窗口/菜单、Dock 生命周期、系统另存为，以及附件、编辑器图片、Reader ZIP、OPML 与备份恢复的系统文件选择器均已完成；0.37 增加渲染界面崩溃后的原生恢复与安全退出，0.35 已提供可供浏览器、快捷指令与未来扩展复用的安全确认式 URL scheme，Share Extension 本体仍待实现。
- [部分完成] 渲染器沙箱、CSP、权限拒绝、Keychain、通用架构、ad-hoc 签名、DMG，以及只允许 Developer ID 正式包使用的自动更新均已完成；hardened runtime、App/DMG 公证和可验证更新 ZIP 流水线已接入，仍需真实证书、公证凭据、正式 GitHub Release 与 Apple Silicon 真机升级验收。
- [部分完成] 应用快捷键、菜单命令、分别默认关闭且仅显示聚合计数的后台导入/订阅通知、按文章去重的独立专注阅读窗口，以及默认关闭、受保护并可删除的 Spotlight 本机索引已完成。系统通知与 Spotlight 结果点击仍需随 Developer ID 签名/公证包验收。
- [已完成] 睡眠/唤醒、离线恢复、电池电量不高于 20% 与系统严重热/降频状态下的后台调度策略；待恢复锁和系统条件不会互相绕过。

验收标准：全新 Mac 可安装、首次启动可用、升级不丢数据，并通过 Gatekeeper。

## M4：AI 阅读工作台

- [部分完成] 可配置兼容 Reader action 契约的远程服务与回环本地模型，macOS 密钥进入 Keychain；提供商预设与模型目录仍待实现。
- [已完成] 单篇翻译、多资料结构化整理/远程创作，以及文章级来源回链。
- [部分完成] 确定性分块、增量词法索引与本地优先 RAG 已完成；可选本地嵌入、向量召回和混合重排仍待实现。
- [已完成] 每次派生结果保留模型、提示词版本、来源文章和用户编辑历史；对话回答提供段落级来源片段、原文偏移和可点击回链。

验收标准：回答可追溯到原文段落；未授权时不上传正文；用户能逐任务选择本地或远程处理。

## M5：订阅与连接器

- [已完成] YouTube 频道通过公开 Atom Feed 接入，不需要账号令牌。
- [已完成] RSS/YouTube 去重、条件请求、失败退避和来源健康度。
- [已完成] 可观测的同步中心：上次结果、上次错误、下次运行时间、开关与频率。
- [已完成] X 通过官方 API 接入，Bearer Token 保存到 Reader 独立 Keychain 项。
- [已完成] 微博通过开放平台官方 CLI 接入，Reader 不接触 CLI 管理的 OAuth Token。
- [已完成] 账号令牌生命周期、限流、增量游标、测试与撤销授权。

验收标准：连接器失效不会拖垮主应用；授权随时可撤销并能清理对应凭据。

- [已完成] v8 不可变 bootstrap、逐版本事务迁移、固定名称与 SHA-256 审计，以及失败时结构/版本/审计原子回滚。

- [已完成] 权限收紧、全文/RAG 索引重建、修复前完整备份、核心故障闭锁和修复后复检，以及具备校验、当前完整备份、重启原子替换和重新迁移前提的迁移快照恢复。数据库结构、外键与附件不会自动猜测修复。
- 可选端到端加密多设备同步；本地单机模式继续作为默认。
- [部分完成] 10 万条内容的列表、筛选、检索、统计与长正文载荷门禁已完成；文章卡片、顶层模态框、侧栏资料夹树、Markdown 编辑器保存、高亮批注管理及静态正文只读 Range 选取具备明确的键盘/ARIA 契约。0.36 使模态框背景和较低层窗口成为实际 inert 子树，并阻止菜单或程序化焦点逃逸；0.34 为产品导航、内容区、阅读器和文章助手建立命名 landmarks、文章加载播报与“减少动态效果”支持；0.31 已在打包候选 App 上完成原生 AX 当前项、切换值、文章描述与 AXPress 状态变更验收。最终包原生 AX 复验、启用 VoiceOver 的完整人工听读和国际化仍待推进。

## 优先顺序

下一迭代建议取得 Apple Developer ID，运行已接入的 App/DMG 公证流水线，发布首个携带 universal 更新 ZIP 的正式 GitHub Release，并在 Intel 与 Apple Silicon 真机完成 Gatekeeper、0.40→0.41 自动升级、系统通知、Spotlight 结果点击及资料库不丢失验收。代码内可在现有确认式 URL scheme 上实现 Share Extension，并继续完成启用 VoiceOver 的人工听读与剩余语义审计；其后推进国际化、可选本地嵌入与混合重排。
