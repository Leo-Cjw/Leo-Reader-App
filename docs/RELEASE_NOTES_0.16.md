# Reader 0.16.0

本版本补齐阅读后的知识沉淀闭环：正文不再只是“读完或收藏”，而是可以在本机持续积累高亮与自己的理解。

## 高亮与批注

- 在正文中用鼠标或键盘选中文字，弹出轻量高亮工具。
- 支持琥珀、苔绿、雾蓝和柔粉四种颜色，可在创建时直接添加批注。
- 高亮使用 CSS Highlight API 呈现，不向 Markdown 或文章 HTML 注入标签。
- 每篇文章底部提供本地批注区，可定位原文、编辑批注、切换颜色和明确删除。
- 刷新或重新启动后按渲染文本偏移恢复；正文发生变化时按精确原文和最近旧位置重新锚定，无法匹配的批注不会丢失。

## Local-first 数据闭环

- Schema v7 为高亮增加文章级索引；数据仍写入同一个本地 SQLite。
- 高亮随文章级联删除，并自动进入现有明文或加密完整备份。
- 备份恢复测试证明高亮 ID、批注和颜色能够完整往返。
- Markdown 导出格式升级为 v2，在文章末尾保留高亮与批注，manifest 同时记录颜色、文本偏移和时间。
- API 限制原文、批注、颜色和偏移范围，不接受 DOM、HTML 或可执行内容。

## 质量门禁

- 53 项自动测试全部通过。
