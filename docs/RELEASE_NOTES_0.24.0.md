# Reader 0.24.0

本版本为 Reader 的全部顶层模态框建立一致的键盘和焦点契约。打开窗口后焦点进入当前任务，Tab 不会落到被遮挡的三栏界面，Esc 复用窗口自己的安全关闭路径，关闭后焦点回到原触发控件。数据结构和 API 均未变化，数据库 schema 保持 v10。

## 统一模态焦点管理

- 应用根部新增单一 `DialogAccessibilityManager`，自动覆盖全部 14 个 `aria-modal` 对话框，不需要在每个业务组件中复制键盘代码。
- 窗口出现时优先保留现有 `autoFocus`；否则聚焦第一个可见、未禁用控件，没有控件时让对话框自身可聚焦。
- Tab 和 Shift+Tab 在最上层窗口的首尾控件之间双向环回，被遮挡的侧栏、列表和阅读器不再进入焦点顺序。
- Esc 只点击当前窗口中未禁用的既有“关闭…”按钮，不绕过编辑器未保存确认、导入清理或忙碌状态的禁用边界。
- 管理器持续记录最近一次位于窗口外的焦点。普通关闭、数据安全切换到本地日志等窗口替换完成后，最终都会回到最初的触发按钮。
- 高亮保存浮层不是顶层模态窗口，不会被错误纳入焦点约束。

## 真实键盘回归

- “添加内容”保留 URL 输入框的自动焦点。
- 从最后一个“加入导入队列”按钮按 Tab 会回到“关闭添加窗口”；从首个关闭按钮按 Shift+Tab 会回到最后一个操作。
- 在输入框按 Esc 关闭窗口后，焦点恢复到标题栏“添加”按钮。
- “数据安全中心”打开后焦点进入关闭按钮；Esc 关闭后恢复到左侧“数据安全”。
- “数据安全中心 → 本地运行日志”的窗口替换保持原始触发器，关闭日志后仍回到左侧“数据安全”。
- 上述流程控制台没有警告或错误。
