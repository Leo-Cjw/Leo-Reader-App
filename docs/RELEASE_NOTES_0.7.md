# Reader 0.7.0

本版本把 Reader 从“能收藏和阅读”推进到“能长期整理大量资料”的本地内容库。

## 树形资料夹

- 新增完整的资料夹管理窗口，可创建顶层或子资料夹、改名、调整上级与安全删除。
- 父资料夹会聚合所有后代内容和计数；选中父资料夹即可查看整棵子树。
- 防止循环层级、同级重名、自删除和系统资料夹删除。删除目录子树时，文章在同一事务中安全移回收件箱。

## 批量整理与归档

- 内容列表支持多选和全选，可批量移动、收藏、标记已读、添加或移除标签。
- 新增归档视图；批量归档不会删除本地正文和附件，归档内容可随时恢复。
- 单篇阅读页也可直接移除标签、归档或恢复，并使用完整树形路径移动内容。
- 批量变更在一个 SQLite 事务中完成，避免部分成功造成资料状态不一致。

## 筛选与图库

- 新增网页、订阅、附件、笔记和媒体筛选。
- 新增双列画廊视图，使用本地缩略图、PDF 预览和视频首帧；视图偏好保存在本机。
- 左侧栏新增标签筛选、归档计数和真正的多层资料夹导航。

## 数据与质量

- 保持 Schema v4，无破坏性迁移；现有 0.6 资料库可直接升级。
- 31 项自动测试全部通过，新增树形约束、子树计数、安全删除、批量标签和归档恢复覆盖。
- 发布门禁保持为 `npm audit --audit-level=moderate`、`npm test` 和 `npm run build`。

## 尚未包含

- 拖拽资料夹排序、智能目录、重复内容合并和选择性导出进入下一轮 M2。
- 原生 macOS 壳、Keychain、Share Extension、签名与公证仍需要完整 Xcode/Swift 工具链。
