# Reader 0.10.0

本版本把文章助手扩展为一个可追溯的 AI 阅读与创作工作台，同时坚持本地数据默认不出设备。

## 翻译

- 文章助手新增 8 种目标语言的翻译入口。
- 翻译只在用户明确配置远程 AI 服务并点击生成后发送当前文章。
- Reader 不会用词语替换或模板拼接冒充翻译；未配置服务时入口会解释原因并保持禁用。
- 译文作为新的 Markdown 文章保存，可继续编辑、进入版本历史、打标签、导出和备份。

## 跨文章创作

- 在内容列表多选最多 20 篇资料，选择资料综述、写作提纲、长文或社交媒体草稿。
- 可选择 8 种成稿语言、保存资料夹和自定义写作要求。
- 未配置远程 AI 时，使用完全本地的结构化整理：提取来源中的明确内容并标注 Reader 来源 ID，不补写来源之外的事实。
- 配置远程服务后，点击生成前会明确说明哪些正文将被发送。

## 来源追溯

- 每个派生文章记录任务类型、来源文章、目标语言/成稿格式、提供方、模型、提示词、提示词版本和生成时间。
- 阅读页显示 AI 草稿标识、处理方式和来源文章按钮，可一键回到原文。
- 派生文章使用既有 Markdown 编辑器和版本历史，不锁定为不可修改的 AI 输出。

## 服务契约与安全

- 网关统一使用 `action` 契约，支持 `summarize`、`chat`、`translate` 和 `compose`。
- 请求超时 60 秒，响应限制 2 MB；跨文章输入限制 20 篇和约 24 万字符。
- AI 状态接口只公开能力状态，不泄露端点或 API 密钥。
- 保持 Schema v4，无破坏性迁移；0.9 资料库可直接升级。
