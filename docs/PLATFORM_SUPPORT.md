# Reader 平台支持矩阵

本文档是 Reader 平台能力与内容边界的唯一事实源。README、路线图、SOP 和发行说明只能摘要并链接到这里，不能扩大这里的承诺。实际操作步骤与验收方法见 [IMPORT_SOP.md](IMPORT_SOP.md)。

## 状态定义

| 状态 | 含义 |
| --- | --- |
| 完整支持 | 有稳定的专用流程、离线或订阅语义明确，并进入发布回归 |
| 专用部分支持 | 有平台专用解析，但平台的一部分内容类型或媒体仍不保证 |
| 通用网页尽力导入 | 只使用通用可读性提取；成功与完整度取决于公开页面 |
| 仅订阅 | 只支持官方订阅源或账号时间线，不代表支持任意单条内容离线 |
| 规划中 | 已进入后续路线，但当前版本不提供专用能力 |
| 不支持 | 当前明确拒绝或不承诺；不会用“尽力导入”包装成支持 |

## 下一阶段：阅读型核心

微信内嵌媒体、CSDN、掘金和知乎的专用适配进入抖音收口之后的阅读型核心路线。它们不会回填到 1.1.x，也不会在专用回归完成前升级为“完整支持”。

## 通用文件与导出

Reader 支持 PDF、常见图片、MP4/MOV/M4V/WebM、MP3/M4A/AAC/WAV 和 Markdown/纯文本附件，单文件上限 100 MB。图片、视频、音频与 PDF 均参与媒体筛选、Markdown ZIP、完整备份和恢复；模型文件、平台 Cookie、临时文件及抖音签名地址不参与任何导出或备份。
