# Reader 安全边界

## 默认信任模型

Reader 默认只监听 `127.0.0.1`。本地 HTTP API 没有账号系统，安全前提是服务不暴露到局域网或公网。不要在不了解风险时修改 `READER_HOST`。

Reader 启动时把默认数据目录权限设为 `0700`，数据库及现有 WAL/SHM 文件设为 `0600`。这限制其他本机用户直接读取资料库，但不能防御已经取得当前用户权限或设备解锁权限的进程。

## 网络导入

- 仅允许 HTTP/HTTPS。
- 每一跳解析全部 DNS 结果；任一结果属于环回、私网、链路本地、CGNAT、IPv6 ULA、保留地址或云元数据地址即拒绝。URL 中的用户名或密码也不被接受。
- 实际 HTTP/HTTPS 连接只使用刚刚通过校验的具体公网 IP，并保留原域名完成 Host、TLS SNI 与证书身份验证；禁用跨请求连接复用。每次重定向重新解析并绑定，避免 DNS rebinding 在检查后把连接切换到内网。
- 限制重定向次数；15 秒超时覆盖连接和完整响应体。gzip、deflate 与 Brotli 在解压后仍受 4 MB 正文或 12 MB 图片上限约束。
- 代表图片和正文图片复用相同 SSRF 与跳转校验，单张限制为 12 MB、单篇本地化预算 48 MB，并同时核验 HTTP MIME 与 PNG/JPEG/WebP/GIF/AVIF/HEIC 文件签名。
- 正文图片本地化失败时转换为显式在线链接，不在阅读时静默加载第三方图片；文章会显示部分离线或仅正文离线。
- 微信公众号导入使用浏览器兼容请求头和专用静态解析器；环境验证页会被拒绝，不会作为文章写入。解析过程不执行页面脚本。

## 附件

- 单文件最大 100 MB，流式写入权限为 `0600` 的随机暂存文件。
- 文件名只作为显示信息；磁盘存储名由 SHA-256 和受限扩展名组成。
- 仅接受 PDF、常见图片/视频、Markdown 和纯文本；可执行格式被拒绝。
- 真实磁盘路径永不返回给前端。媒体端点强制 `nosniff` 并支持受控 Range。
- PDF.js 目前与主进程同进程运行。原生版应把不受信任文档解析迁移到沙箱子进程。
- 编辑器文章图片另设 20 MB 上限，只接受 PNG、JPEG、WebP、GIF、AVIF 和 HEIC，并同时校验文件签名；声明为图片的伪造内容会在挂载前删除暂存文件。
- 编辑器不提供附件物理删除，避免破坏文章历史版本中的资源引用。相同字节通过 SHA-256 复用本地文件。

## 自动订阅

- RSS、Atom 和 YouTube Feed 复用网页导入的公开 URL、DNS、重定向、超时与 4 MB 响应体限制。
- ETag 与 Last-Modified 只作为下一次同源请求的缓存校验头，不执行或解析为代码。
- 后台调度只处理已启用且到期的来源；单个来源同步去重，失败状态落库并指数退避，最长 24 小时，不会阻塞其他来源或主服务。
- OPML 使用无实体展开的受限属性解析，最多 500 个来源；每个地址仍逐一通过公开 URL 校验。导入错误按来源隔离并返回摘要。
- YouTube 只接受官方频道页、`/channel/UC…` 或 `feeds/videos.xml`，视频与播放列表地址不会被误当作频道订阅。
- X 只接受 1–15 位用户名或 `x.com`/`twitter.com` 用户主页；API 主机固定为 `api.x.com`，不接受用户提供的端点。Bearer Token 通过标准输入写入独立 macOS Keychain 项，不进入进程参数、SQLite、OPML、备份、导出或 API 响应。
- 微博只接受数字 UID 或对应个人主页。Reader 查找并直接执行开放平台官方 `@weibo-ai/weibo-cli`，关闭 shell，限制执行时间与 JSON 输出大小；OAuth Token 由 CLI 自己管理，Reader 不读取它。
- X 与微博图片在入库时复用现有公开 URL、重定向、MIME、签名、大小和 SHA-256 去重边界；下载失败会显式降级，不在阅读时静默加载。
- 社交游标、平台用户 ID、配额剩余和重置时间属于非敏感同步状态，可进入 SQLite 与 OPML 以外的本地运行记录；OPML 只导出账号主页和同步设置，不导出任何凭据。

## Markdown 与 AI

- Markdown 预览不启用原始 HTML，因此文章无法注入脚本或事件处理器。
- 高亮只保存用户主动选择的纯文本、有限偏移、允许的颜色和本地批注；不保存 DOM、HTML 或可执行内容。原文最长 5,000 字符，批注最长 20,000 字符，偏移必须是有界递增整数。
- 正文着色使用浏览器 CSS Highlight API，不向 Markdown 注入标签；正文变化导致锚点失配时只在本机按精确原文和最近旧位置重定位。
- 默认摘要和结构化整理完全本地。翻译只在用户启用有效的远程网关后可用，Reader 不提供会被误认为真实翻译的本地替代品。
- 界面会在发送前说明处理边界；远程请求只在用户点击生成、翻译或提问后发生。AI 状态 API 不返回端点和密钥。
- 单次跨文章创作最多 20 篇来源、约 24 万字符；请求 60 秒超时，响应最大 2 MB，网关结果必须是符合契约的 JSON。
- 派生文章保存在本地，并记录来源文章 ID/标题、任务、语言、提供方、模型、提示词版本和生成时间。远程服务自身的数据保留策略仍由服务提供者决定。
- macOS 上由 Reader 保存的 API 密钥进入独立的系统 Keychain 通用密码项；密钥不会写入 `settings.json`、SQLite、备份、导出或设置 API 响应。环境变量仍可作为未保存设置时的默认值。
- 非敏感的启用状态和端点保存在权限为 `0600` 的 `data/settings.json`。远程端点强制 HTTPS，本机模型只允许回环 HTTP；URL 中的用户信息、片段和疑似密钥查询参数会被拒绝。
- 连接测试只发送 Reader 内置文本，不读取资料库正文；更新设置失败时会回滚本次 Keychain 变更。
- RAG 问答先在本机检索。远程网关只收到最多 8 个命中片段，每片最多 2,000 字符，不收到整篇文章或整个资料库；零命中时不发起远程请求。
- 引用 ID、标题、原文片段和偏移来自本地索引，不接受远程服务构造任意引用。远程返回的 `citationIds` 只允许引用本次已发送的候选集合。
- 弱相关候选必须通过词组覆盖与相对分数阈值；证据不足会显式返回空引用，避免把无关内容包装成依据。

## 备份与恢复

- 备份使用 SQLite 一致快照，不直接复制运行中的 WAL 数据库。
- schema 升级同样在任何结构变更前使用 `VACUUM INTO` 创建一致快照，校验 `integrity_check` 后以 `0600` 权限保存在 `data/migration-backups/`；快照列表只接受 Reader 生成的严格文件名，下载以不缓存、`nosniff` 的私有端点提供且不暴露磁盘路径。检测到高于当前支持版本的 schema 时拒绝降级打开，不执行写入或迁移。
- 升级快照恢复只接受本机列表中的快照 ID，不接受任意 SQLite 上传。安排和实际启动替换前均验证文件哈希、实际来源 schema、SQLite 完整性与外键；未来 schema 快照会被拒绝。Reader 先暂停导入与订阅并创建包含当前数据库和附件的完整安全备份；待恢复期间写 API 失败闭锁，只读浏览和资料库检查可继续，取消后恢复后台任务与写入。下次启动仅替换数据库、保留附件并重新执行受审计迁移。升级后新增或修改的数据库记录不会留在活动资料库，但仍可从安全备份恢复。
- schema v8 作为不可变 bootstrap；后续迁移按连续版本注册，每个版本在单独事务内同时提交结构、版本号与审计记录。启动时核对迁移的固定名称和 SHA-256，已发布历史缺失、未知或被改写时停止打开。
- 资料库体检必须由本机用户打开数据安全中心或调用 POST API 明确触发；检查过程不写 SQLite，响应只含状态、数量、耗时和数据库大小。正文、标题、附件名、存储名、记录 ID、错误原文与磁盘路径均不返回；内部文件错误统一映射为通用响应。
- 受控修复必须由用户在数据安全中心确认或显式调用 POST API；同一时间只运行一项修复，导入任务或待重启恢复存在时拒绝开始。
- 自动修复只允许收紧数据目录、数据库和 SQLite sidecar 权限，或从权威文章表重建词法全文、trigram 子串和 RAG 派生索引。索引写入前必须创建完整 `pre-repair` 备份，写入后重新执行全套健康检查；失败时备份保留。
- SQLite 页损坏、外键失效、迁移历史异常、附件缺失或大小不符会关闭自动修复。Reader 不自动伪造附件、删除未引用文件、修改正文或猜测关系；修复 API 不返回正文、附件名、存储名、记录 ID、manifest 或磁盘路径。
- 归档只允许 `reader.sqlite3`、`manifest.json` 和 `files/`；拒绝绝对路径、`..`、反斜杠、符号链接和未知路径。
- 解压限制条目数、单条目声明大小和总展开大小，防止路径穿越与压缩炸弹。
- 恢复前验证 manifest 版本、数据库哈希、每个附件哈希和 SQLite `integrity_check`。
- 恢复只安排在下次启动执行；Reader 会先创建一份恢复前安全备份，再原子替换数据库和文件目录。
- 加密备份使用随机 salt、scrypt（N=65536、r=8、p=1）和 AES-256-GCM；格式头作为附加认证数据，密文任何位置被修改都会导致恢复失败。
- 备份口令至少 12 个字符，只在当前创建或恢复请求的内存中使用，不写入数据库、manifest、日志或待恢复标记。遗忘口令后无法恢复。
- 解密结果仅写入权限为 `0600` 的随机恢复暂存目录；认证或后续完整性校验失败时整个目录被清理。

## 本地诊断日志

- Reader 不启用遥测，也不自动上传诊断数据。本地日志只在本机回环 API 和数据安全中心中可见，用户可以导出或清除。
- 日志事件与字段均为代码内固定白名单。禁止记录标题、正文、摘要、URL、来源名、附件名、存储名、记录 ID、磁盘路径、错误原文、堆栈、API Key、社交令牌或备份口令；未知事件和未知字段直接丢弃。
- 意外服务错误只记录请求方法、无 ID 的功能分组、HTTP 状态与有限错误类别；渲染器只收到“无法完成请求”，不收到内部异常文本。JSONL 读取与导出再次清洗，不能借由篡改本地日志让任意内容进入响应。
- `data/logs/` 为 `0700`，日志文件为 `0600`；每个文件最多 512 KB，最多三份，超出自动轮转。日志不进入完整备份、Markdown 导出或设置文件，日志写入失败也不会阻断资料库。

## 可迁移导入导出与重复治理

- 导出仅接受本地文章 ID，单次最多 500 条；附件路径必须解析在 `data/files/` 内，缺失或越界会拒绝整次导出。
- ZIP 中的 Markdown 使用安全文件名和相对附件路径；manifest 和 v3 sidecar 不写入数据库路径、附件存储名、AI 密钥、社交令牌或备份口令。
- 导出响应禁止缓存并强制 `nosniff`。导出属于用户主动下载，不改变本地文章状态。
- Markdown ZIP 导入只接受 `reader-markdown-export` v2/v3；其他 ZIP、完整备份和任意 Markdown 压缩包不会走这条写入路径。
- 预检拒绝绝对路径、`..`、反斜杠、符号链接、加密条目、重复路径和清单以外文件；压缩包上限 2 GB、展开总量上限 5 GB、单附件上限 100 MB、文章上限 500 篇，并限制条目数量和单个 manifest/Markdown/sidecar 大小。
- 每个清单附件在预览阶段重新核对实际字节数与 SHA-256；清单统计、文章/附件 ID、记录路径、URL 协议、高亮范围和阅读进度也必须通过受限校验。
- 暂存根目录与导入目录权限为 `0700`，文件为 `0600`；预览 token 为不可推导 UUID，API 不返回磁盘路径。取消、提交或 24 小时过期都会递归清理暂存包。
- 用户必须逐篇选择并指定资料夹；相同 Reader ID 或 HTTP(S) 原链接默认跳过，导入不会隐式合并或覆盖现有文章。
- 重复检测只使用本地精确规范化哈希，不会联网。整理操作不删除文章或附件，副本移入归档并记录保留版本 ID，可人工恢复。

## 智能资料夹与拖放

- 智能资料夹规则只接受已知字段、受限内容类型、最多 10 个标签、最长 200 字符关键词、最长 120 字符来源，以及 1–3,650 天的时间窗口；空规则被拒绝。
- 规则值全部经过 SQL 字面量转义，不接受客户端 SQL、列名、排序表达式或可执行代码。“任一满足”仍始终附加未归档基础条件。
- 智能资料夹只保存规则和顺序，不复制、移动或删除文章；删除智能资料夹不会改变任何内容。
- 拖放文章复用现有原子批量移动接口，一次最多 500 条。资料夹排序要求完整同级 ID 集合，缺失、重复或跨层列表会被拒绝。

## 缩略图

- 图片和 PDF 缩略图只在本机生成，源文件上限 100 MB，图片解码后拒绝超过 1.6 亿像素的内容。
- PDF.js 禁止动态求值且只渲染第一页；输出为固定尺寸 WebP，不携带原始文档脚本或链接。
- 缩略图缓存不进入备份，资料库恢复后自动清空。
