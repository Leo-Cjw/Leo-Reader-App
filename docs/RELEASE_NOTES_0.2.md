# Reader 0.2.0

这一版本把 Reader 从“可运行资料库”推进为“可恢复的本地内容工作台”。

## 新增

- PDF、图片、视频、Markdown 与文本附件。
- 100 MB 流式上传、SHA-256 幂等存储和安全格式白名单。
- PDF 本地文字抽取与全文索引。
- 持久化导入队列、任务状态、错误展示、重试和重启恢复。
- 本地文件私有读取端点与视频/PDF Range 支持。
- 任意文章双栏 Markdown 编辑器、实时预览、标题/作者/来源/摘要编辑。
- GFM 表格、列表、引用、代码块和安全 Markdown 渲染。

## 质量

- 自动测试从 6 项增加到 10 项。
- Vite 升级至 6.4.3，`npm audit` 为 0 漏洞。
- 浏览器完整验收覆盖附件选择、队列完成、Markdown 阅读、编辑和持久化。

## 已知边界

- 尚未生成图片/视频缩略图。
- 网页图片仍引用原始站点，尚未完整本地化。
- Markdown 编辑器暂未提供版本历史和自动保存。
- 原生 `.app`、Keychain、签名和公证仍需要完整 Xcode 工具链。
