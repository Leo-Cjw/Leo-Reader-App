# Reader 0.49.0

本版本完成可选本地嵌入、向量召回与混合重排，同时保留 Reader 原有全文检索作为默认和故障回退。功能默认关闭，不改变远程 AI 配置，也不会把正文发送到远程嵌入服务。

## 本地语义检索

- 设置窗口新增独立的“本地语义检索”。模型测试只发送 Reader 内置英文；用户明确启用后，才分批把本地分块交给同机 Ollama。
- 嵌入地址固定为 `http://127.0.0.1:11434/api/embed`，不可通过设置、环境变量或请求改写；请求不带 API Key，并拒绝 HTTP 重定向。
- 支持手填已安装的 Ollama 嵌入模型，推荐 `embeddinggemma`、`qwen3-embedding` 或 `all-minilm`。批次最多 16 段，每段最多 2,000 字符；请求设置 `truncate: false`。
- 查询先保留现有 FTS/中文词组候选，再从 LSH 桶读取有限向量候选并计算精确余弦，使用 reciprocal-rank fusion 混排。界面区分混合检索、全文检索和全文回退。
- Ollama 未运行、请求超时、索引未完成或模型维度变化时，Reader 仍返回现有词法结果，不让本地问答失效。

## 数据兼容与可恢复性

- Schema 从 v11 升级到 v12，新增 `chunk_embeddings` 与 `chunk_embedding_buckets`；升级前继续创建一致性 SQLite 快照，并写入固定名称与 SHA-256 迁移审计。
- 向量保存为单位化 Float32 BLOB，schema 强制校验维度、字节长度、模型、桶范围和外键；每个向量必须有完整 16 组 LSH 桶。
- 片段 ID 已包含正文哈希。文章编辑、版本恢复或删除会通过外键级联清除旧向量；后台结果只有片段 ID 和内容哈希仍匹配时才落库。
- 同名模型返回不同维度时自动清空并重建，防止混用不兼容向量空间。
- 关闭功能会等待当前批次结束并删除全部派生向量和桶；文章、附件、全文索引、远程 AI 设置和 Keychain 凭据不受影响。
- 全文/RAG 受控修复会一并清理损坏的派生向量；启用状态下随后重新建立。后台索引服从睡眠、低电量、严重热/降频和资料恢复锁。

## 安全与验证

- 139/139 项自动测试通过。新增覆盖固定回环、无认证头、重定向拒绝、响应边界、向量序列化、LSH 稳定性、纯语义命中、混排、正文编辑失效、维度变化、词法回退、关闭清理、schema v11→v12 和设置 API。
- 10,003 片段、30 轮查询性能门禁：词法检索 p50 20.66 ms、p95 24.32 ms；LSH 向量召回与精确余弦 p50 64.00 ms、p95 69.28 ms，均低于 250 ms 门槛。
- 生产构建、依赖审计、Universal x64/arm64 合并、签名回读、全部 14 个顶层模态框 AX、Share 文本/文件/取消/URL，以及冻结 0.43 schema v11 资料库升级闭环继续作为阻断门禁。
- 最终包设置 AX 会检查具名的本地嵌入模型、测试与启用控件，但保持默认关闭，不连接 Ollama 或创建向量。
- 升级门禁确认冻结资料库迁移到 schema v12 后语义索引仍默认关闭、派生向量为零，再验证文章、资料夹、标签、高亮、版本、智能资料夹、待处理导入、设置、附件、继续写入、重启、SQLite 完整性和附件 SHA-256。
