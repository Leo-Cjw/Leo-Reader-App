# Reader 0.3.0

本版本聚焦“内容真正留在本机”和“数据可以放心恢复”。

## 新能力

- URL 导入会解析 Open Graph / Twitter Card 代表图片，并在 SSRF、MIME、文件签名和大小校验后保存为本地附件。
- 文章编辑自动生成不可变版本快照；可预览、恢复旧版本，恢复操作本身也会生成新版本。
- 数据安全中心可一键创建包含 SQLite、附件和 SHA-256 清单的 `.readerbackup.zip`。
- 恢复包会验证归档路径、条目规模、数据库与附件哈希以及 SQLite 完整性。
- 恢复安排在下次启动执行；安排前自动创建安全备份，启动时原子替换数据库和附件目录。

## 质量门禁

- `npm audit --audit-level=moderate`：0 个已知漏洞。
- `npm test`：15 项测试全部通过，包括完整备份创建、破坏性修改、恢复安排、重启应用和数据/附件还原演练。
- `npm run build`：生产构建通过。
- 真实浏览器验收：编辑生成版本、恢复旧版本、恢复最新内容、创建完整备份、下载入口与成功提示均通过，控制台无错误。

## 已知边界

- 网页正文内嵌图片尚未全部本地化；当前本地化代表图片。
- 缩略图、Readability 级正文抽取和自动保存仍在后续 M2 范围。
- 备份尚未加密；当前应依赖 FileVault 或受信任的加密磁盘。
- 原生签名、公证、App Sandbox、Keychain 和 Share Extension 需要完整 Xcode 工具链，属于 M3。
