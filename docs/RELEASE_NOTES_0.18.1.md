# Reader 0.18.1

本维护版本让用户能够在不上传资料、不修改数据库的前提下，确认本地资料库是否具备继续使用和创建备份的基本健康条件。

## 资料库体检

- 数据安全中心新增六项检查：SQLite 页结构、外键关系、迁移审计、本机权限、附件可用性和本地检索索引。
- 打开数据安全中心时自动检查，也可随时点击“重新检查”。
- 正常、警告和错误状态在明暗主题下使用同一套紧凑状态卡呈现。
- 检查不会尝试自动修复；发现异常后应先创建或保留恢复点，再执行受控诊断。

## 本机权限加固

- 默认数据目录在启动时收紧为 `0700`。
- 数据库及现有 SQLite WAL/SHM 文件收紧为 `0600`。
- 现有 0.18.0 schema v9 不变，不创建迁移，升级后可直接使用原资料库。

## 隐私边界

- 健康检查 API 只返回状态、数量、耗时、schema 版本和数据库大小。
- 响应不包含文章标题或正文、附件名、存储名、记录 ID、原始错误或磁盘路径。
- 内部文件系统错误统一返回“无法完成资料库检查”，避免通过异常消息泄漏本机目录。

## 质量门禁

- 63 项自动测试全部通过，包含断裂外键、附件缺失、权限放宽、检查只读性和 API 异常脱敏故障注入。
- TypeScript/Vite 生产构建通过，依赖审计为 0 个已知漏洞。
- 10,003 个本地片段、30 次查询的独立检索基准 p95 为 34.57 ms，低于 250 ms 门禁。
- 数据安全中心在 1280×720 窗口完成浅色/深色真实交互和布局验收。
- Universal App 检出 x86_64 与 arm64 双架构，ad-hoc 深度签名验证通过；DMG 通过 `hdiutil verify`，SHA-256 为 `a22c2fa31bfb0dc02b358b36e682d51304b52a8cd579c63284199cd036e1dd51`。

## 已知边界

- 检查可以发现附件缺失或大小不符，但不会自动删除孤立文件或重建用户数据。
- Developer ID 正式签名、Apple 公证、自动更新和双架构真机安装升级验收仍未完成。
