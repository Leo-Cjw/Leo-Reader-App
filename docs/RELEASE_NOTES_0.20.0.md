# Reader 0.20.0

本版本让 Reader 的运行状态变得可诊断，同时继续守住 local-first 的隐私边界：用户可以在数据安全中心查看、导出和清除本地日志，但 Reader 不记录阅读内容，也不启用遥测。

## 本地运行日志

- 新增“数据安全中心 → 查看本地日志”，展示启动、退出、启动失败、完整备份、恢复安排/取消、受控修复和意外本地服务错误。
- 日志以 JSONL 保存在 `data/logs/`，目录权限为 `0700`、文件为 `0600`。
- 单文件最多 512 KB，最多保留当前文件与两份轮转文件，总预算约 1.5 MB。
- 可以从界面导出经过二次清洗的 JSONL，或清除全部日志；清除不影响文章、附件和备份。
- 日志写入串行落盘，但任何日志故障都不会阻断资料库或应用退出。
- schema 仍为 v9，0.19.x 用户升级不需要数据库迁移。

## 隐私与错误收口

- 每种事件都有固定字段白名单；未知事件和未知字段不会写入。
- 不记录标题、正文、摘要、URL、来源名、附件名、记录 ID、磁盘路径、错误原文、堆栈或任何凭据。
- API 只返回无 ID 的功能分组和有限错误类别；读取和导出时再次执行白名单清洗，本地文件被手工加入任意字段也不会回显。
- 意外 500 响应不再把内部异常原文返回界面，而是统一为通用错误；开发终端也只输出脱敏类别。
- 日志不进入完整备份、Markdown 导出、设置文件或网络请求，不会自动上传。

## 质量门禁

- 74 项自动测试全部通过。新增覆盖日志权限、轮转上限、字段白名单、篡改后二次清洗、启动失败留痕、意外 500 脱敏、JSONL 导出、备份事件和真实清除。
- TypeScript/Vite 生产构建通过，依赖审计为 0 个已知漏洞。
- 10,003 个本地片段、30 次查询的检索基准 p50 为 27.65 ms、p95 为 35.15 ms，低于 250 ms 门禁。
- 1280×720 下完成浅色与深色日志中心浏览器验收，弹窗无横向或纵向溢出。
- Universal App 检出 x86_64 与 arm64 双架构，版本元数据为 0.20.0，ad-hoc 深度签名验证通过；DMG 通过 `hdiutil verify`。
- `Reader-0.20.0-universal.dmg` 大小为 254,452,431 字节，SHA-256 为 `05e1a1d1a94238ffb7420ca9c5351a6b608f2ae8a01bf1287249ef1763f2e7f4`。

## 已知边界

- 当前日志聚焦生命周期、数据安全动作和意外服务错误；不会记录每次阅读、搜索或编辑行为。
- Reader 仍不提供匿名遥测。未来若增加，必须默认关闭并由用户明确同意。
- 迁移快照仍只提供查看和导出：当前版本直接恢复旧快照会丢弃之后数据并重新执行同一迁移，因此不会提供误导性的一键回滚。
- Developer ID 正式签名、Apple 公证、自动更新和双架构真机安装升级验收仍未完成。
